# 设计模型与工程需求文档

## 一、设计理念
- **现代简约**：采用简洁的设计语言，突出企业专业形象
- **用户中心**：以用户需求为核心，优化用户体验
- **品牌一致性**：保持品牌视觉识别系统的一致性

## 二、色彩方案
### 主色调
- **天蓝色**：#0077BE（品牌标识、按钮、重要元素）
- **深蓝色**：#003B5C（文字、强调元素）

### 辅助色
- **浅天蓝色**：#4DA8DA（背景、区块）
- **超浅天蓝色**：#97CAEF（边框、分隔线）

### 中性色
- **白色**：#FFFFFF（主要背景）
- **浅灰色**：#F5F7FA（区块背景）
- **中灰色**：#E5E7EB（边框、阴影）
- **深灰色**：#333333（主要文字）

## 三、排版方案
### 字体选择
- **标题字体**：Inter（无衬线字体）
- **正文字体**：Roboto（无衬线字体）

### 字体层级
```
H1: 3rem (48px), 700, #003B5C
H2: 2.25rem (36px), 600, #003B5C
H3: 1.875rem (30px), 600, #003B5C
H4: 1.5rem (24px), 600, #003B5C
H5: 1.25rem (20px), 600, #003B5C
H6: 1.125rem (18px), 600, #003B5C
正文: 1rem (16px), 400, #333333
小号正文: 0.875rem (14px), 400, #666666
辅助文字: 0.75rem (12px), 400, #999999
```

## 四、布局规范
- **响应式断点**：360px (移动端), 768px (平板), 1200px (桌面)
- **容器宽度**：最大1200px，居中对齐
- **间距规范**：8px基础单位，采用8的倍数（8px, 16px, 24px, 32px, 40px, 48px, 64px, 80px, 96px）

## 五、组件设计
### 导航栏
- **桌面端**：水平导航，Logo + 菜单项 + 联系按钮
- **移动端**：汉堡菜单，折叠式导航

### 按钮
- **主要按钮**：天蓝色背景，白色文字，圆角8px
- **次要按钮**：白色背景，天蓝色边框和文字，圆角8px
- **链接按钮**：文字链接样式，悬停效果

### 卡片
- **产品卡片**：图片 + 标题 + 描述 + 按钮
- **服务卡片**：图标 + 标题 + 描述
- **案例卡片**：图片 + 标题 + 客户名称

### 表单
- **输入框**：浅灰色背景，无边框或细边框，圆角6px
- **标签**：加粗文字，与输入框间距8px
- **提交按钮**：主要按钮样式

## 七、交互设计
- **导航交互**：悬停效果，下拉菜单
- **按钮交互**：悬停变色，点击反馈
- **表单交互**：实时验证，提交反馈
- **滚动效果**：平滑滚动，视差效果
- **模态框**：信息展示，确认对话框

## 八、性能要求
- **页面加载时间**：< 2秒
- **图片优化**：WebP格式，响应式图片
- **代码分割**：按需加载
- **缓存策略**：合理设置缓存

## 九、SEO要求
- **元标签**：每个页面设置独立的title和description
- **结构化数据**：添加Schema.org标记
- **Sitemap**：生成网站地图
- **Robots.txt**：配置搜索引擎爬取规则
- **URL结构**：简洁友好的URL
