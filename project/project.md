# 现代商业企业型Astro网站项目文档

## 项目概述
这是一个基于Astro框架开发的现代商业企业型综合网站，采用天蓝色和白色为主色调，旨在展示企业形象、产品和服务，并提供用户交互功能。

## 项目目标
- 建立专业的企业在线形象
- 展示公司产品和服务
- 提供便捷的客户联系方式
- 实现良好的用户体验和响应式设计
- 优化网站性能和SEO
- 部署在Vercel平台

## 技术栈
- **框架**：Astro 5.16.6
- **样式**：Tailwind CSS
- **部署**：Vercel
- **版本控制**：GitHub
